# Chronicle

What changed just before this broke?

Chronicle (`nshkr.chronicle`) is a local-first desktop incident flight recorder
for Omarchy. It brings timestamped evidence, bounded resource history,
bookmarks, before/after comparisons, and saved investigations into one native
panel. Correlation is not proof of causation.

**Development status:** being built and tested outside the installed desktop.
Do not install or enable during the current isolated acceptance phase.

See [the implementation plan](docs/IMPLEMENTATION-PLAN.md) for architecture,
research, safety boundaries, milestones, and the deferred installed acceptance
gate. MIT © 2026 nshkrdotcom.
